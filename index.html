How I work

From brief to build

Roughly how each project above came together, whether it was solo or with a team.

01

Discover

Understand who the product is for and what problem it actually needs to solve, before opening Figma.

02

Define

Map out the core flows and the data behind them — what a user does, and what the system needs to store.

03

Design

Wireframe and design the interface in Figma, then test it against the flows from the step before.

04

Develop

Build it out — front end first, then wire up the back end and database, and fix what breaks.

Smart Buy Grocery

Role

Front-end developer

Stack

HTML, CSS, JavaScript

Type

Solo project

Smart Buy is a grocery ordering website built entirely with vanilla HTML, CSS and JavaScript, with no framework involved on purpose. I wanted to get comfortable with layout, responsiveness and interactivity using only the fundamentals before reaching for a library.

That meant hand-building the product grid, cart logic and responsive breakpoints myself, which forced me to actually understand what frameworks like Tailwind or React usually handle automatically.

Event Management System

Role

Full-stack developer

Stack

C#, MySQL (XAMPP)

Type

Solo project

A system for organising and managing events end to end — creating events, tracking attendees and handling the underlying records. The database runs on MySQL through XAMPP, with the application logic written in C#.

This one was less about the interface and more about getting the data model right: figuring out how events, attendees and bookings should relate to each other before writing a single screen.

Skincare & Beauty Website

Role

Full-stack developer

Stack

PHP, TailwindCSS, JavaScript, XAMPP

Type

Solo project

A storefront for skincare and beauty products, styled with TailwindCSS on top of a PHP back end, with a MySQL database managed through XAMPP.

Role

Full-stack developer

Stack

Laravel, PHP, MongoDB, TailwindCSS

A second pass at the skincare platform, this time rebuilt on the Laravel framework with MongoDB instead of MySQL as the database.
